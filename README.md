### 🧠 Engineering Mindset

I’m less interested in just writing application logic and more obsessed with:

- **How code executes at the kernel boundary** – OS primitives, memory layouts, and non-blocking I/O state machines
- **How data flows under extreme network load** – Socket-level protocol design, buffer flow control, and thread-blocking elimination
- **How to observe runtime behavior in real time** – Using eBPF and telemetry pipelines to trace async scheduling and profile latency bottlenecks
- **How to build bare-metal resilient systems** – Enforcing strict memory caps, sanitizing system-level inputs, and writing code that holds up under high concurrency
